# AGENTS.md

## Agent skills

### Issue tracker

Issues live in GitHub Issues for `Teekola/electricity-app`, managed with the `gh` CLI. See `docs/agents/issue-tracker.md`.

### Triage labels

The five canonical triage roles, using the default label strings (`needs-triage`, `needs-info`, `ready-for-agent`, `ready-for-human`, `wontfix`). See `docs/agents/triage-labels.md`.

### Coding standards

Escape hatches (`any`, `!`, `as`) and comment style. Read before writing or reviewing code. See `docs/agents/coding-standards.md`.

### Domain docs

Single-context: one `CONTEXT.md` plus `docs/adr/` at the repo root. See `docs/agents/domain.md`.
